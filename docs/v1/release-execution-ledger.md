Purpose: connect the proposed v1 inventory to candidate owners, existing local receipts, and the cumulative release evidence still required. This is an execution ledger, not a feature-completion report. Existing receipts support bounded slices only; they do not imply the full row or any candidate package passed. The inventory/reconciliation and the independent audit are dated planning inputs, not a live issue-board refresh. Before pulling work, check current issue state and freeze the minimum where marked unresolved.

Status codes follow the 2026-10-19 independent audit: **S** minimum/owner boundary still needs finishable reconciliation; **O** plausible open owner, with exact required subset still to finalize; **E** bounded minimum accepted, cumulative release qualification open; **R** cross-cutting release obligation; **I** shared infrastructure; **X** bounded experiment only; **L** later roadmap. These labels do not say code is absent or present. Issue keys below are candidate accountability links; `(c)`/`(o)` reflects that audit’s dated local snapshot only. Receipt links are existing local records, not candidate-package evidence. Shared fixtures are intentional.
