# REL-024: Extrude form and fixed actions at minimum width

The Extrude dock now scrolls its form while keeping OK and Cancel in a fixed footer. The form wraps long label/editor rows within the existing dock width. An incomplete To Object extent says “Select an end face for the extrusion.” instead of exposing reference-field names.

The focused [Qt run](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-03/qt.log) passed 3/3 on the production theme. [Normal To Object](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-03/normal-to-object.png), [1040×640 To Object](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-03/minimum-to-object.png), and [minimum Distance ready](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-03/minimum-distance-ready.png) captures show the field/footer separation. At minimum size, settled form content and viewport were both 270 logical pixels wide. The test checks horizontal bounds, complete visible end-face guidance, disabled OK for missing end face, and actual `widgetAt` ownership of the footer buttons. It uses `ensureWidgetVisible` to frame the guidance for capture; this is programmatic scroll setup, not a pointer or keyboard scrolling claim.

The 20×12 mm sketch and the two Extrude sessions are created with Alloy's shared API. A real Qt Cancel click on incomplete To Object leaves authored features and undo state unchanged. A valid 8 mm Distance session then commits through the actual visible OK button, retaining one Extrude after the Sketch and producing approximately 1,920 mm³. The [solid capture](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-03/committed-solid.png) and [saved model](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-03/extrude-dock-model.alloy) are from that same run. The capture is immediately after commit, before a separate settled post-commit layout check; it establishes the solid, not final dock reflow. This checks the dock route and result without replaying a full tutorial.

Earlier [qt-01](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-01/qt.log) and [qt-02](../../../Alloy-reference-records/deliverables/rel024-extrude-dock-2026-10-14/qt-02/qt.log) reached the actual footer actions but failed overly strict test assertions: qt-01 forgot the authored Sketch when counting features, and qt-02 compared the OCCT volume for exact floating-point equality. The final assertion uses a 1e-6 mm³ tolerance. Physical pointer scrolling and other platforms remain unqualified under REL-013.
