# Retained planar Offset Face (SOL-067/#512, SOL-072/#598, SOL-073/#599)

Alloy now offsets one selected planar face of a closed solid along its outward normal using a signed distance. It retrims neighboring faces through OCCT's local offset operation, retains one editable `faceOffset` history feature, and gives the moved face an exact feature-owned support identity. The Solid > Modify > Offset Face route, `solid.faceOffset` local command, native dock and timeline edit use the same document operation. The dock supports command-first viewport picking, active mm/in distance, live preview, OK, Cancel and Escape. A zero initial distance is an Alloy choice because the public references do not establish a default.
