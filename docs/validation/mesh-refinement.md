# Selected-solid mesh refinement preview (PRT-011/#643)

One committed solid instance can now be previewed as the **final serialized** binary/ASCII STL or Core 3MF mesh before export. The Save As Mesh sheet offers Low, Medium, High and Custom refinement, explicit surface and normal deviation, a GPU facet overlay and the final triangle count. The preset numbers are Alloy policy (Low 0.5 mm/25°, Medium 0.1 mm/10°, High 0.02 mm/5°); public evidence does not establish exact reference-product values. Changing settings or selection clears the count and requires another Preview. Save publishes the prepared bytes atomically without remeshing. Preview and Cancel do not alter authored geometry, history or Undo.

The independent real-app fixture at `../Alloy-reference-records/validation/mesh-refinement-2026-10-20/run-01/` exercised a selected, translated cylinder occurrence. Binary STL Low/Medium/High/Custom produced 112/284/572/956 final triangles, with independently measured maximum cylinder chord errors of 0.058622/0.009518/0.002381/0.000858 mm. ASCII STL in inches and Core 3MF with a serialized placement transform each produced 284 triangles. Independent readers checked one-solid scope, units, bounds and transform; in all six cases the preview count and SHA-256 matched the saved artifact, and saved bytes equaled the prepared bytes. The fixture also checked a failed publication and retry, Cancel during pending preparation, late-generation discard, and invalidation on selection, document and tab changes. Source document, history, Undo state and an existing sentinel file were preserved. Each measured fixture publication took 0 ms at timer resolution; this does not qualify very large exports for UI responsiveness.

The accepted local Release build used `-j4`. Focused compiled mesh controls passed 9/9, and existing serialized-normal and pole-facet checks passed. Actual Apple M4 OpenGL captures `Low-preview.png` and `High-preview.png` show distinct GPU facet density and full visibility of the selected cylinder; `refinement-sheet.png` shows readable controls. The large centered sheet obscures much of a part and remains a native presentation limitation. Physical pointer/chooser and matched 1×/2× visual qualification remain PRT-014/#689 while the Mac console is locked. Publicly documented Maximum Edge Length and Aspect Ratio are PRT-013/#690; multi-body one-file/per-body export and collision-safe batch behavior remain PRT-012/#644. No CI was run.
