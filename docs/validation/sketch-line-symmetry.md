# SKT-079 — retained two-line Symmetry

2026-10-14. Public command evidence and its limits are in external `../Alloy-reference-records/knowledge/specs/sketch-symmetry-child-choice-2026-10-14.md` (public help, retrieved 2026-10-14). The source documents two selected geometries followed by a symmetry line and a persistent badge. The exact endpoint matching rule, badge placement, and default tool behavior are unknown; the choices below are Alloy conventions.

`sketch.constraint` and the Sketch Constraints palette now accept `symmetry` with exactly two existing authored straight lines followed by one distinct construction line. The shared command solves the current draft, chooses the unique lower-residual endpoint correspondence (including reversed second-line direction), then retains all three line IDs and four point IDs. Later edits do not rematch endpoints. Two PlaneGCS point-pair equations share one retained constraint UUID, independently checked against solved reflected coordinates. A collapsed axis, ambiguous match, invalid retained endpoint references, an incompatible alternate pairing, caller-supplied point pairing, incompatible geometry, or a third non-construction pick refuses without committing a different draft. A valid reversed second-line pairing is allowed. One axis-anchored badge can be picked and deleted, removing both equations together. Sketch Mirror remains a separate entity-creation feature.

The focused core `sketch_symmetry` passed: a reversed second side yields the intended endpoint IDs; a source point edit remains reflected; wrong retained pairing and caller point injection refuse; undo/redo and save/reopen preserve the authored relation. The real Alloy API fixture `tests/sketch_symmetry_api.py` passed 42 calls from a 60×30×5 mm plate to 70×30×5 mm: volume 9000→10500 mm³, side endpoints at ±35 mm, exact relation ID, a conflicting 61 mm width refusal with unchanged draft, undo/redo, and reopen. Four connected ordinary lines plus only nonredundant axis/side constraints form the fixture. Alloy's Rectangle tool automatically authors Horizontal/Vertical relations that make this particular added Symmetry rank-redundant; it is not a substitute source for this gate.

The focused Qt-native `sketch_symmetry_controls` passed 3/3 after initial application activation. It clicked the actual Symmetry palette button, then the left and right viewport lines; a wrong third line left both picks pending, and a construction-axis click authored the relation. The same test checked one visible glyph for the UUID, Escape to Select, actual badge click, and Delete. It asserted viewport focus before both keys and did not repair focus between steps. The native fixture intentionally has open independent lines; the palette's open-loop warning is expected and does not describe the separate closed-plate API fixture. This is Qt-delivered input evidence, not OS pointer parity.
