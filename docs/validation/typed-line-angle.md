# Typed Line angle candidate (SKT-070)

The active Line command now has separate Length and Angle fields. A first click followed by `4`, Tab, `55`, Tab and a second click creates a 4 mm Euclidean line and a 55° driving angle to an authored horizontal construction reference. Tab locks input without changing the sketch draft; click commits one draft history step and continues the Line chain. The construction reference shares the line start and has one free endpoint, so a later Coincident can place that endpoint on a projected corner and remove its final DOF. The pointer chooses the preview ray for the bounded 0–180° angle; the exact historical quadrant behavior of the source tutorial remains unknown. Existing length-only Tab then click retains its horizontal/vertical behavior.
