# Per-body mesh destination chooser (PRT-016/#692)

Save As Mesh now separates the existing **Parent Folder** (with **Browse…**) from the editable **New Folder Name** for One Body Per File. The sheet wraps and displays the exact computed destination and generated filenames before Save. Invalid names, missing parents and existing file/directory/symlink targets disable or refuse Save with actionable feedback. Chooser Cancel returns to the sheet without changing the model or creating output. The export still uses PRT-012's exclusive new-directory publication; existing-directory replacement remains PRT-015.

The final local Release build used `-j4`; the focused compiled mesh-controls suite passed 11/11. Its pointer test delivered to the actual Browse button, observed the native Directory chooser request, programmatically rejected it, checked focus/state return, delivered a chooser result signal and confirmed parent-path update, edited name/parent, and compared the displayed destination with the shared command input and resulting two-file output. Programmatic chooser rejection and signal delivery do not establish physical native chooser behavior.

The independent real-app fixture in `../Alloy-reference-records/validation/batch-destination-2026-10-20/independent-final/` passed 52 responses. Two unequal selected Boxes exported to new per-body STL and Core 3MF directories; separate readers confirmed each file's one-body scope, 12 triangles, bounds, volumes and millimeter placement. Existing file/directory/dangling-symlink sentinels and missing-parent refusals preserved output and authored/evaluated/revision/Undo/selection state; a stale selection refused, Undo/Redo remained usable, and saved source bytes stayed unchanged. An initial fixture comparison incorrectly expected the evaluation revision counter to remain fixed after a deliberate Undo/Redo; the corrected final run passed without a product change.

Inspected Apple M4 OpenGL 4.1/Metal-backed DPR2 full-app captures show readable Browse, name, wrapped full destination and filenames. The centered sheet obscures much of the part. Physical chooser selection/Cancel, native keyboard traversal, viewport-visible placement and matched 1×/2× qualification remain PRT-014/#689; Windows/Linux packaged runtime remains a release gate. Exact public layout/default parity is unknown. No CI ran.
