# REL-021 compact ribbon and navigation

At a 1040 × 640 logical window on the current 2× macOS display, the primary ribbon previously compressed its icon groups and the navigation labels collided. The ribbon now keeps two existing commands per group visible at narrow widths—Sketch and Extrude in Create, Combine and Fillet in Modify—and retains every command in its named group menu. The Construct group gained a menu for its existing commands. The navigation bar keeps Home, Fit and Camera visible, moving the remaining controls into Navigation and View menus when its full row no longer fits. The Navigation button names the active tool. Width decisions compare the available row width with the full row's Qt size hint; the breakpoint is an Alloy presentation policy, not a claimed reference threshold. The ribbon keeps its 94px height because the representative icons remain visible.

The focused [Qt run](../../../Alloy-reference-records/deliverables/rel021-responsive-controls-2026-10-14/qt-01/qt-07.log) passed 3/3 in the production-theme Release build. It captures [1360 × 850 normal](../../../Alloy-reference-records/deliverables/rel021-responsive-controls-2026-10-14/qt-01/normal-idle.png), [1040 × 640 minimum](../../../Alloy-reference-records/deliverables/rel021-responsive-controls-2026-10-14/qt-01/minimum-idle.png), [active Pan](../../../Alloy-reference-records/deliverables/rel021-responsive-controls-2026-10-14/qt-01/minimum-pan-active.png), and the [minimum Box dock](../../../Alloy-reference-records/deliverables/rel021-responsive-controls-2026-10-14/qt-01/minimum-box-dock.png). The minimum captures show readable group icons, menu names and navigation labels without collisions. Actual Qt popup activation, menu-row hit ownership and normal closure were asserted for Navigation → Pan and Create → Box. A viewport Pan drag changed the shared camera state; natural canvas focus and Escape returned to Select. Create → Box opened the real `solid.box` session. The test uses the same AlloyWindow and authoritative commands as the application; it does not claim physical OS pointer testing or every menu action was clicked.

The earlier Qt-05 fixture sent Escape to the viewport while the Box dock was also active and Pan remained selected; it did not record the natural focused recipient, so that observation is not a product defect conclusion. The accepted Qt-07 route tests Pan/Escape before opening Box. A long status strip still clips at the minimum size and remains in REL-013, outside this ribbon/navigation fix. Other modeling dock and failure-state visual audit work remains under REL-013.
