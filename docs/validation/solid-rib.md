# Retained symmetric To Next Rib — SOL-066/#511

Accepted bounded result: **Solid > Create > Rib** adds one thickness-controlled rib from an earlier open straight sketch Line to one earlier closed target solid. Thickness is symmetric perpendicular to the sketch plane; the span follows sketch normal × directed Line and stops at one full-cover planar face perpendicular to that span. Flip reverses the span direction. The feature stores the sketch/entity, target body and resolved source/stop face IDs; editing thickness or moving the same support face recomputes the same target body, while an unavailable, partial, curved or ambiguous stop refuses rather than switching silently. The shared `solid.rib` command and native Rib dock use the same candidate evaluation. Other directions, starts, extents, profile families and Web modes remain under ADV-006.

Public command evidence, illustration links and unknown native defaults live outside the repository at `../Alloy-reference-records/knowledge/specs/sol066-rib-web-2026-10-20.md`. The restricted support rule, span sign convention and numeric fixture are Alloy choices. Exact matched-reference panel styling and installed UI defaults remain unknown; native canvas picking and thickness drag are separately owned by SOL-097/#693. The current dock offers explicit Profile and Target Body selectors, thickness entry and Flip.

The independent real-app [fixture](../../tests/rib_independent_api.py) creates a single U-channel solid from a 40×30×2 mm base and two 40×2×21 mm walls with 1 mm overlap into the base. Its union is **5,600 mm³**. A line `(2,1,4)→(38,1,4)` with 2 mm symmetric thickness and +Y span creates a rib tool of 1,944 mm³, 72 mm³ overlapping the near wall, and a joined solid of **7,472 mm³**. Editing thickness to 3 mm gives **8,408 mm³**. Moving the far wall from y=28 to y=26 while returning thickness to 2 mm gives **7,328 mm³**, preserving the target body and pinned support face identities. Raising the source plane/sketch Line from z=4 to z=5 retains the same volume and support pair. The same real-app run checks disposable preview/Cancel, an invalid-thickness atomic refusal, Undo/Redo and authored save/reopen. Focused core tests separately certify a partial-stop refusal without changing revision or Undo.

Independent binary STL readback of the edited solid finds **one watertight component**, **56 triangles**, exact `[0,0,0]`–`[40,30,22]` mm bounds and **7,328 mm³** signed volume. The Apple M4 GPU capture at DPR 2, OCCT OpenGL 4.1 through Metal, shows the original native isometric preview and a right orthographic silhouette. The right view visibly separates the new rib shelf from the channel base; it is not a clipped section. The default isometric camera lets the near wall obscure much of the rib. Native Qt actual-hit testing passes Create-menu Rib, popup row Profile/Target selection, typed 2→3 mm preview, Cancel, OK, Timeline edit, invalid Flip preview and Escape. No focus/selection repair was inserted. The native test calls the shared command to reopen a populated second dock; it does not demonstrate all fields selected by pointer on that second pass. Its private editor and the independent fixture editor both closed.

An independent Astra source review found that repinning an earlier Rib originally read the final target body's support summary, which a later Rib could overwrite. Commit `2fe5620` resolves supports at the edited Rib's history prefix. A focused two-Rib regression passes with distinct opposite support pairs, an earlier Profile edit, unchanged later authored Rib and exact 9,344 mm³ final volume. The accepted Release build used Qt 6.11.2 and `-j4`; focused Rib core and native tests pass. No CI was launched. Evidence is at `../Alloy-reference-records/validation/sol066-rib-2026-10-20/native/` and `../Alloy-reference-records/validation/sol066-rib-2026-10-20/independent-final/` (model, STL, transcript, report and actual GPU captures). Physical Mac input, native canvas picking/thickness handle (SOL-097), matched layout and Windows/Linux packaged GPU remain separate gates. A printable watertight STL is established for this analytic fixture, not arbitrary rib support geometry or a physical print.
