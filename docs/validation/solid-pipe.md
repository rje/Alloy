# Retained hollow circular Pipe — SOL-061/#506

Accepted bounded result: **Solid > Create > Pipe** creates one new, editable hollow circular solid along an earlier retained open tangent sketch Line/Arc chain. The command stores ordered path entity/start IDs, outer diameter and wall thickness; Full, Perpendicular and New Body are the supported values. Other sections, extents, operations and paths remain in ADV-005. The public command research and dated source links are kept outside the repository at `../Alloy-reference-records/knowledge/specs/sol061-retained-pipe-2026-10-20.md`. Defaults and the mixed Line/Arc selection gesture are Alloy choices where that evidence does not establish exact reference behavior.

The shared local `solid.pipe` command and native dock use the same authored candidate. The dock exposes Path, Chain Selection, Section Size and Section Thickness; Create-menu actual-hit, line/arc path pick, typed diameter, live GPU preview and Cancel passed the focused Qt test without focus repair. The first native test failed despite a triggered Pipe action because the new numeric schema's implicit maximum was zero. Explicit bounds fixed that command-registration defect; the final test passed. The failed and final logs plus the whole-app capture are retained at `../Alloy-reference-records/validation/pipe-2026-10-20/native/`. Physical device input, 1× presentation and exact matched-reference layout remain unqualified under the cumulative release gate.

OCCT sweeps an annular face along the same retained G1 path resolver used by solid Sweep. Pipe requires a finite positive diameter, `0 < wall < diameter/2`, and an arc centerline radius larger than the outside tube radius. It checks one valid closed positive-volume solid and geometric self-interference. Both builder-proven end faces must be unique planar two-wire annuli; they receive stable `pipe.start`/`pipe.end` support IDs. Unsupported, branched, disconnected, non-tangent, too-tight and interfering paths refuse without committing partial geometry. The existing circular-profile Sweep core regression remains green after the shared-path extraction.

The independent real-app fixture [pipe_independent_api.py](../../tests/pipe_independent_api.py) builds a 30 mm line tangent to a 10 mm-radius quarter arc. Its expected path length is `30 + 5π` mm. At 4 mm outside diameter / 1 mm wall, exact OCCT volume is **430.787405 mm³**. Editing the same feature to 6 mm diameter gives **717.979008 mm³**; changing the wall to 1.5 mm gives **969.271661 mm³**. Moving the source line start by 5 mm recomputes the same body/feature IDs and gives **1075.300413 mm³**. The run checked preview without history mutation, Cancel, an invalid-wall atomic refusal, Undo/Redo and exact authored save/reopen. It captured the actual Apple M4 GPU preview/committed views at DPR 2; both annular openings and the selected centerline are readable. The prior and final independent ledgers, model, screenshots and export are at `../Alloy-reference-records/validation/pipe-2026-10-20/independent-final/`.

Independent binary-STL readback found one closed, consistently oriented mesh with **9,000 triangles**, Euler characteristic **0**, millimeter bounds `[-3,-5,-2.998]` to `[10,43,2.998]`, and signed volume **1074.168474 mm³** (about 0.105% below the analytic value at the selected tessellation tolerance). The mesh has no open boundary and preserves the bore; this is geometry/export evidence, not a physical print-fit test. The Mac renderer reported Apple M4, OCCT OpenGL 4.1 through Metal, 4× MSAA and a native 2056×1216 framebuffer. Windows/Linux packaged GPU and input validation remain GATE-050.

Local Release build used the accepted Qt 6.11.2 SDK in `build-preview-release` with `-j4`. Focused Pipe/Sweep core tests passed 2/2; the native Pipe control test and the independent real-app fixture passed. No CI was started. The private editors closed after each test.
