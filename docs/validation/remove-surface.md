# HIS-007: retained Remove surface body

The bounded Remove operation adds one `removeBody` feature for one current local surface body. The feature retains its body UUID and original modeling owner. Evaluation removes the sheet from the active body set while preserving its source sketch and surface feature in history. Undo, deleting Remove, or rolling back before it restores the same surface identity. Authored body names and Browser owner mappings remain stored during intentional removal, then reapply on restoration. A downstream reference to the removed body or a missing upstream source fails atomically. Imported occurrences, solids, and multi-body selection are outside this slice.
