# Extrude Offset start candidate

Status: isolated SOL-044 candidate, independently accepted for this bounded ingredient on 2026-10-13; integration remains pending. The public command contract, source provenance and independent review are held outside the repository in `../Alloy-reference-records/knowledge/tutorials/advanced-audit-2026-10-13/project-offset-start-contracts.md` (SOL-044) and `sol044-independent-review.md` beside it. The historical public label "Offset Plane" maps to the current documented Start > Offset choice. The public sign rule is explicit: a positive start offset follows the source profile plane normal. Alloy's initial Profile Plane/zero selection is a compatibility choice; an exact public default was not established.

Start offers Profile Plane or Offset. Offset is an independent signed length, applied along the authored sketch normal before the signed one-side Distance. Thus the evaluated prism spans `S + offset*N` to `S + (offset + distance)*N`, while the sketch stays on its original support. A direct positive user-length name can bind Offset by stable parameter ID; a signed literal such as the source's -10 mm is entered numerically. General expressions and To Object are outside this issue. The same `CadDocument` feature and evaluation serve native controls and `solid.extrude`, `solid.extrudeDialog` and session updates. Existing Profile Plane extrusions retain their prior storage shape.

The actual generated face and edge lineage, end-cap support frame, patterned extrusion seed, target discovery, live Cut tool and viewport arrow all use the shifted start. A zero-distance or invalid name cannot be committed; failed evaluation leaves the authored document unchanged. The native Start selector conditionally reveals Offset. Edit restores mode, value or direct name. Typing a literal replaces a prior name, including the same numeric value.

Focused core `extrude_offset_start_test` passes shifted New Body bounds, generated cap frame, a downstream sketch attached to that cap, unchanged source support, stable bound offset through rename/update, missing-ID atomicity, undo/redo and save/reopen, numeric replacement, and independence from the Distance sign. An XZ front sketch with normal -Y and Offset -10 / Distance +5 evaluates between world Y=5 and Y=10 while its source remains at Y=0; its attached cap sketch resolves at Y=5. `extrude_offset_start_controls_test` passes Qt Start-mode selection and native typed offset entry, preview/Cancel, unknown-name attempted commit refusal, direct name entry, bound edit reopen, literal replacement and second edit reopen. `tests/extrude_offset_start_api.py` passes through the real application entrypoint with a front ellipse on a 50×80×40 Box: the offset Cut removes `400π mm³`, survives edit, undo/redo and save/reopen, and leaves the original front sketch unchanged.

Native and real-app captures were inspected and preserved outside the repository at `../Alloy-reference-records/deliverables/extrude-offset-start-2026-10-13/candidate-01/`; the API transcript and saved model are in its `api/` subdirectory. The displayed front profile and Start/Offset fields are readable at the tested viewport. The divot is internal and does not appear on the reopened exterior from the tested isometric camera, so the bounds/sign assertion rests on the core fixture and the Boolean volume assertion rests on the real-app API. This receipt does not claim the complete advanced tutorial, exact visual parity, or Windows/Linux runtime.
