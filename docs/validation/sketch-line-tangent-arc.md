# Line hold-drag tangent Arc — SKT-086

The active Line chain now accepts a press at the latest committed Line endpoint, a held drag to preview a connected analytic Arc, and release to commit it. The same Line tool resumes from the new Arc endpoint. The retained Arc shares the incoming Line endpoint ID and has one signed `arcTangent` relation to that Line. The next straight Line reuses the Arc end ID; it receives no automatic outgoing Arc tangency.

Preview and release use the same analytic construction: the incoming Line direction fixes the Arc's start tangent, and the drag endpoint determines its center, radius and signed sweep. Degenerate or nearly straight releases refuse without adding geometry. Preview does not author the Arc. A press without drag and Escape during drag preserve the committed Line. Release after cancellation is consumed without a second Line placement. The 10-logical-pixel endpoint press radius and 4-pixel drag threshold are Alloy input policies; exact public thresholds are unknown.

The focused core `sketch_line_tangent_arc` passes the analytic arc, exact shared IDs, retained incoming tangent, straight continuation and invalid collinear-release checks. The actual Qt test passed 3/3 in `../Alloy-reference-records/deliverables/sketch-line-tangent-arc-2026-10-14-native-05.log`. It uses API setup for the blank sketch and Line tool, then actual Qt pointer clicks to make the incoming Line, press/held move/release for the Arc, and a click for the outgoing Line. It asserts the held state has no new authored entity, no-drag and Escape leave the prefix unchanged, release commits the Arc, and Finish, undo/redo and save/reopen preserve the authored sketch.
