# SKT-082 — explicit circle-line Tangent

2026-10-14. The compact public command contract and source provenance are recorded outside the repository at `../Alloy-reference-records/knowledge/specs/sketch-circle-line-tangent-child-2026-10-14.md`. Public evidence establishes a circle and line Tangent command but does not settle every contact rule. This bounded Alloy implementation preserves its existing finite-line contact rule, retained constraint schema, solver and badge.

The Sketch Constraints Tangent button and shared `sketch.constraint` command accept one existing circle and one straight line in either pick order. The current solved sketch determines a retained signed side; a center on the line refuses as ambiguous. The retained relation uses the existing `tangent` record with ordered circle and line IDs. Caller-supplied contact points or side, duplicate pairs, incompatible geometry and failed solves refuse without changing the draft. The solver checks signed center-to-line distance and that the contact foot lies on the finite line. The existing shared-endpoint arc-line path remains separate under the same button. Other curve combinations remain outside this child.

The focused core test verifies finite contact, canonical identity, duplicate and ambiguous-side refusal, undo/redo and reopen. The real Alloy API fixture passed 40 calls: it authors a circle tangent to a construction datum, changes radius 5→7 mm and datum offset 10→12 mm, and checks the same retained relation, solved contact, selectable circle region, history and reopen. Its GPU capture shows the edited circle touching the dashed datum and a visible constraint badge. These checks do not establish arbitrary circle placement or visual parity with the public reference.

The focused Qt-native control test passed 3/3 after one initial application activation. Actual Qt-delivered clicks use the Tangent palette button and sketch geometry in both circle→line and line→circle order. It checks the retained record and glyph, then clicks the badge and presses Delete after verifying viewport focus. The line click is on an exposed segment away from the circle contact. The capture shows the constraint badge and highlighted palette button. Programmatic shared-command calls create the test fixture; no OS pointer parity is claimed.

Evidence: `../Alloy-reference-records/deliverables/sketch-circle-line-tangent-2026-10-14/api-01/` has the real-app result, authored model and GPU captures; `native-02/` has the passing native log and capture. The earlier native-01 reverse-pick failure clicked the circle at the tangent point and is retained as diagnostic evidence, not a product failure.
