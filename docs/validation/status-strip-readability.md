# REL-023: concise status and persistent warnings

The status strip now shows a short live summary of renderer, body count, view, zoom, and active tool. Its tooltip and accessibility description retain the complete navigation/chord hints and GPU detail. Recovery failure and GPU-unqualified states use separate permanent markers with full diagnostic text in tooltip and accessibility description. The redundant development-preview label was removed from this strip. Qt temporary messages continue to use the ordinary status-bar message path.

The [focused Qt run](../../../Alloy-reference-records/deliverables/rel023-status-strip-2026-10-14/qt-02/qt.log) passed 3/3 on the production theme and current macOS patched Qt runtime. [Normal](../../../Alloy-reference-records/deliverables/rel023-status-strip-2026-10-14/qt-02/normal-status.png) and [1040×640 Pan](../../../Alloy-reference-records/deliverables/rel023-status-strip-2026-10-14/qt-02/minimum-pan-warning.png) captures show the summary and Recovery unavailable marker fully readable. The test checks label bounds and text widths, complete tooltip/accessibility metadata, Pan and Orbit captions through shared commands, and that a temporary status message does not hide or erase the permanent recovery warning.

The warning is a genuine local initialization refusal: `ALLOY_RECOVERY_DIR` points to a regular file. It demonstrates presentation and metadata for that error, not loss or recovery of user work. The development Mac reports a qualified hardware GPU, so the test verifies the GPU marker is hidden according to actual diagnostics; unqualified hardware presentation is source-reviewed, not runtime-injected. The first focused run [failed](../../../Alloy-reference-records/deliverables/rel023-status-strip-2026-10-14/qt-01/qt.log) because the initial status could precede viewport GPU initialization. A queued refresh after the actual viewport Show event and hiding the marker after status-bar insertion corrected that lifecycle; the final run did not force a modeling command to repair status. Other platforms and physical input remain outside this gate.
