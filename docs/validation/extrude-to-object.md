# Retained planar To Object extent candidate

SOL-043, 2026-10-13. Independently accepted bounded ingredient; integrated on main; combined build and focused core checks pass.

The candidate authors an end-face reference and a separate signed end offset.
GeometryKernel resolves the current earlier face and sketch frame for each
recompute; no calculated distance is stored as driving intent. The same resolver
serves preview, target discovery and committed New Body/Cut. A direct named user
length may drive the end offset. Start offset remains independent.

The bounded target is a perpendicular retained planar face, extended as a plane.
Positive clearance stops short of it in either direction; negative offset extends
past it. This sign policy is an explicit inference from the public lid lesson,
not a universal documented convention. Body targets, adjacent-face extension,
oblique/curved termination, Join/Intersect and patterned To Object seeds remain
outside this slice. Only an identity root-sibling target may cross ownership;
Cut targets and source profiles retain existing owner restrictions.

Signed extrusion end caps now transport the source axes and preserve the same
semantic role/ID for either distance direction. The actual OCCT face retains its
own orientation. The earlier positive-direction identities are unchanged.
