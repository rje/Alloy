# SRF-013: paired-sketch surface Trim candidate

This bounded Surface Modify > Trim command retains one current local two-face open sheet body, an earlier solved XZ sketch containing exactly two connected ordinary fit splines, and one or two selected inner region IDs. The sketch is the tool selected first. Alloy sweeps each solved spline along the sketch normal in both directions past the projected target bounds with a retained 10 mm default margin; the public source does not establish the reference application's projection default. OCCT Splitter produces one inner and one outer region per source face. Exact common area with the swept closed loop classifies each region, and commit removes the selected inner faces from the original body. The tool sketch and feature history remain authored. Unsupported/nonunique topology and stale region references fail atomically.

Region IDs derive from the Trim feature and source face IDs. Original boundary IDs follow splitter history; new boundaries require unique full-length correspondence to one tool spline and one source face.
