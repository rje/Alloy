# Selected-body batch mesh export (PRT-012/#644)

Save As Mesh now offers **One File** or **One Body Per File** for an explicit committed-solid set in binary/ASCII STL and Core 3MF. One File retains combined STL triangles or separate 3MF objects/build items. Per-body mode shows the selected count and deterministic, portable filenames, prepares every file off the UI thread in a private sibling directory, and publishes one new output directory only after the whole batch succeeds. An existing file, directory or symlink at that destination refuses unchanged. The new-directory rule is an Alloy safety policy; exact reference-product collision behavior is unknown. Single-solid prepared Preview and exact-byte Save remain PRT-011; multi-body modes do not claim a facet preview.

The independent real-app fixture `../Alloy-reference-records/validation/batch-mesh-2026-10-20/independent-final/` created three unequal boxes, exported an explicit two-body subset in all four structure/format combinations, and independently read every STL/3MF output. Combined STL had two closed components and 24 triangles; combined 3MF had two millimeter objects/build items. Per-body directories contained exactly two isolated files. Reversing selection preserved the filename-to-body map. Identical, case-different and unsafe body names yielded distinct deterministic filenames; the excluded body did not leak. A separate rotated/translated occurrence export retained its nonidentity 3MF build transform and world bounds exactly once. Existing file/directory/dangling-symlink sentinels, duplicate/stale selection, and authored/evaluated/revision/Undo/selection preservation passed. The fixture's tiny-box Cancel arrived after publication approval; Alloy explicitly refused that late Cancel, then completed a two-file directory that was independently read. Preapproval denial, failed later-body staging and racing-destination preservation passed focused core tests. No partial final batch was accepted.
