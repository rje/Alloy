# Retained Boundary Fill

Validated 2026-10-15 for SRF-011. Kernel/document commit `f8c00b4` and the
accompanying frontend retain one explicitly selected bounded cell as a New Body
from 2–32 named local surface tools in one root or identity-child modeling owner.
General solid/mixed tools, multiple selected cells and other result operations
remain outside this bounded implementation.

The native Surface Create command and shared API use tools → Select Cells →
actual cell checkbox → New Body → explicit Remove Tools → preview/Cancel/OK.
Remove Tools starts unchecked for this observed workflow state; this is not a
claim about a universal reference default. Duplicate tool names use readable
profile labels while retained IDs stay in item data. No cell is selected by
ordinal, largest volume or marker position.

OCCT MakerVolume uses exact retained sheets, intersection/history and
non-destructive processing without a fuzzy override. Unique source-face
contributors identify each admitted cell; output face/edge ancestry is retained.
Missing or ambiguous contributors refuse atomically. A classifier-qualified
interior point positions the native checkbox only. Warnings remain in inspection;
the UI explains orientation warnings without hiding them or requiring approval
for an otherwise validated selected solid.

New-command tool picks use the current accepted evaluation. Select Cells builds
one immutable partition per exact revision/owner/feature/body/tool set. Cell,
name and Remove Tools changes reuse it. Edit sessions evaluate the required
source prefix once; stale sessions discard their cells and previews. Full commit
performs authoritative evaluation. Remove Tools consumes evaluated bodies only
after the solid exists, preserving source definitions and undo/reopening.

retained IDs, owner gates, ambiguity refusal, exact history and reopening. The
qualified five-sheet iron yields one valid 98,122.002 mm³ solid with seven named
faces; bounded handle-passage witnesses remain separate input-qualification
