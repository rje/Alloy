# Surface Extrude responsive preview

REL-033/#476 addresses the measured Qt main-thread stall when editing a Surface Extrude in the corrected iron workflow. The command now evaluates immutable authored input on a serial background worker. The live window accepts navigation, inspection, input changes and Cancel while it runs. A generation and document-revision guard discards superseded results; Commit uses the completed evaluated candidate rather than repeating kernel work. Cancel discards the result but cannot interrupt an OCCT operation already in progress. New modeling commands and window close wait for that worker to drain.

The saved-iron fixture exercised edit opening and appending a bottom profile through Alloy's real local control API on the development Mac. Edit opening submitted in 99 ms and evaluated for 40.32 s; during that time 156 status calls had a 0.28 ms median and 113 ms maximum, nine pan calls took at most 34 ms, and the GUI heartbeat's maximum gap was 58 ms. Appending the bottom profile submitted in 66 ms and evaluated for 21.23 s; 82 status calls had a 0.29 ms median and 2.5 ms maximum, five pan calls took at most 40 ms, and the heartbeat's maximum gap was 57 ms. The cached Commit took 291 ms. The preview and committed sheets matched across 25 geometry summary fields; the earlier sheet retained its face and edge IDs. Exact authored undo/redo, save/reopen, valid topology and unchanged area passed. The active viewport reported hardware acceleration on Apple M4. Captures show the busy state and reopened result.

Focused Qt tests cover pending state and stale generations, Cancel, the retained edit result, solver-normalized downstream history, no-op history, and the post-Cancel busy message.
