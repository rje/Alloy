# Coil source and history display cost — REL-056/#736

Accepted bounded result: retained Coil history reuses the exact stored display mesh instead of remeshing it when a new AIS drawer is created. A numeric update of directly bound Pitch on one Coil plus retained Moves prepares its fresh geometry/display mesh on the existing serial worker, then commits the exact prepared parameter transaction. Other parameter/name/unit/expression and feature-family routes retain their existing behavior. No display-quality setting, geometry algorithm, authored identity or focus/activation behavior changed.

The matched fixture is the accepted `coil-2026-10-24/api-responsive/spring.alloy`: centerline Diameter 20 mm, circular Section Size 2 mm, four revolutions, named SpringPitch 7 mm, XY center (4,−3) and a retained +3 mm Z Move. Each of two samples starts from the same authored P7 snapshot, updates to P9, undoes to P7 and redoes P9. The first P7 snapshot was loaded/meshed at Open; later P7 observations are historical reuse. Camera, viewport, host and candidate settings match. Two samples establish this bounded mechanism/result, not a broad stable performance distribution.

| Operation | Before wall time | After wall time | After initial response / main-thread work |
| --- | --- | --- | --- |
| Fresh bound Pitch7→9 | 7348 /7164 ms | 7965 /8057 ms total | Dispatch71 /67 ms; pending Inspect173 /182 ms; publication324 /325 ms |
| Undo9→7 | 6413 /14089 ms | 130 /134 ms | Stored evaluation, handler/state under 1 ms; AIS Display about7–10 ms |
| Redo7→9 | 6535 /13642 ms | 140 /123 ms | Stored evaluation, handler/state under 1 ms; AIS Display about7–10 ms |

Before, source evaluation was about718 ms and history push under 1 ms. History did not rebuild geometry: each old/new TShape signature stayed unchanged, while triangulation identities changed despite identical counts/quality. AIS Display consumed 6.2–13.8 s, with selection 2–6 ms and recovery 0–2 ms. OCCT7.9.3's `StdPrs_ToolTriangulatedShape` header documents that own-drawer deflection changes can clear existing triangulation regardless of actual mesh quality. This was redundant remeshing of retained snapshots, rather than history/JSON evaluation cost.

The fix is restricted to body IDs authored by Coil, including the same body through Move, plus the already supported explicit worker-prepared shapes. Before disabling automatic AIS remeshing, it computes the requested deflection and requires OCCT `IsTessellated` qualification. Every face must also have finite stored angular metadata no worse than the requested 0.10 rad; missing metadata fails closed. The existing 0.0005 relative deviation coefficient and 0.10 rad angle remain unchanged. Old mesh identities now remain identical across Undo/Redo. Both candidates have exactly 169,152 display triangles at P7 and 177,248 at P9, with identical per-face quality metadata and node counts. The matched P9 GPU viewport pixels are identical over pixel rectangle `[504,336,2880,1552]` in 2880×1800 captures, on Apple M4/OpenGL 4.1 through Metal. `comparison.json` records the zero difference and exact matched camera.

Fresh source work remains explicit: worker evaluation 899 /887 ms and display meshing 6654 /6731 ms, followed by main-thread publication324 /325 ms. Heartbeats advance 296 /298 ticks with maximum gaps 123 /136 ms. This change removes unnecessary history work and keeps the long fresh update responsive; it does not claim an intrinsically optimal mesher or that total fresh work became faster. Fresh meshing, reopening and broader performance remain in REL-049's budget audit.

The pending Parameters flow disables editable fields while preserving Close and a local **Cancel Update**; a statusbar Cancel also exists. Buttons bind their own operation UUID and disappear when finished/cancelled. Publication checks document identity, exact base/revision, generation and resolved requested candidate. Only one existing stable parameter row may change. Rename/unit/expression-graph edits fall back to the existing route. Cancellation discards private worker shapes without changing committed geometry/history. Raw `command.status` completion preserves the former document-state result keys and document UUID, adding operation metadata/`operationId`; `app.state.coilParameterUpdate` exposes pending progress. Profiling mesh traversal/signatures appear only with `ALLOY_TRACE_COIL_COST`; identity hashes are process-local diagnostics, not persistent model references.
