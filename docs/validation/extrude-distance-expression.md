# Retained Extrude Distance expression

PAR-008 implements arithmetic text in the existing One Side / Distance input. `solid.extrude` accepts one of signed numeric `distance`, direct `distanceParameter`, or `distanceExpression`. It uses Alloy's bounded length grammar (`+ - * /`, parentheses, `mm`/`in` literals, and user length names). Functions and formulas in other Extrude fields remain outside this child. This is a bounded implementation of the public expression capability recorded in the external `knowledge/specs/par001-extrude-distance-expression-2026-10-14.md`; exact formula Return behavior and field styling were not established by the public source.

The feature retains `distanceExpression`, ordered `distanceReferenceIds`, captured `distanceExpressionUnits`, and an evaluated `distanceMm`. Parameter edits recompute the solid; tokenwise rename updates the displayed spelling while retaining UUID references. An unchanged feature edit preserves captured entry units even after display units change. Editing to a number clears formula identity. Signed nonzero values keep the prior Extrude range and direction behavior; zero, out-of-range, incompatible and missing-name expressions refuse atomically.

The focused actual-app API evidence is `../Alloy-reference-records/deliverables/extrude-distance-expression-2026-10-14/api-07/`: a fixed 40×30 mm profile has 80 mm depth/96,000 mm³ with `Width*2`, then 90 mm/108,000 mm³ after Width 40→45. It checks UUID identity on rename, invalid expression and failed source edit with unchanged accepted state, undo/redo, save/reopen, negative signed expression, and a scalar formula authored in inches that remains 152.4 mm after switching display units and reopening its edit session. The model-parameter row shows the retained formula as read-only; an edit there refuses and directs editing through Extrude.

The focused production-theme Qt input gate `extrude_distance_expression_controls` uses API fixture setup, then actual field click, focus-owned text entry `Width*2`, Tab preview, and actual OK click. Reopening the feature displays formula text; `Width+5 mm` also previews from the same field, then Cancel preserves authored data. Qt input and GPU capture are distinct from physical OS input. The accepted full-solid capture with explicit Distance (mm) label and exact 1/1 CTest log are under `../Alloy-reference-records/deliverables/extrude-distance-expression-2026-10-14/native-08/`.
