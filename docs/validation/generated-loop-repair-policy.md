# Generated loop Offset support-repair policy (SKT-161/#593)

Retained loop Offset identity is tied to an exact support face and boundary key. Ordinary recomputation preserves the owner and output IDs when both survive. If the exact boundary changes validly, an explicit recreation must allocate a new owner, loop key and generated IDs; a geometrically similar boundary does not prove lineage. Missing, incomplete, repeated or ambiguous lineage continues to refuse atomically. A generated loop needs a planar face boundary, so an origin or construction plane is not a recreation target. A downstream feature that still consumes the old generated profile blocks the first recreation scope until separately repaired.

The external [dated policy](../../Alloy-reference-records/knowledge/specs/skt161-generated-loop-offset-repair-policy-2026-10-18.md) separates published support-redefinition behavior from these Alloy identity decisions. The [classification receipt](../../Alloy-reference-records/validation/skt161-generated-boundary-policy-2026-10-18/receipt.md) retains saved-valid real-app fixtures for exact-boundary recomputation, a complete changed boundary on the same support face, a valid distinct replacement face, and an old-profile consumer. It also records the existing missing-support and incomplete-boundary failed-edit diagnostics and Cancel. The two valid target documents were independently authored diagnostics: they prove the proposed geometry evaluates and reopens, not that a repair command exists.

[SKT-162/#595](https://github.com/rje/Alloy/issues/595) owns one explicit distinct-face `planarInsetV1` recreation workflow, including old-profile consumer refusal. [SKT-163/#596](https://github.com/rje/Alloy/issues/596) owns the same-face changed-valid route. Classic loop owners, multiple owners, projected boundaries, arbitrary frame reorientation and explicit downstream consumer repair remain open under SKT-025. Public generated-owner repair details, exact visual parity, physical input and other-platform runtime remain unknown.
