# Intentional open-surface STL — PRT-004/#166

Accepted bounded result: an explicitly selected, committed open surface body can be saved as one binary or ASCII STL through the shared `document.exportStl` command or **Save As Mesh** sheet. Preview uses the same final serialized bytes, units and refinement settings as closed-solid STL. The surface row and persistent warning say **Open surface — non-solid** and explain that the sheet has zero thickness and is not a printable solid. The API result reports `bodyType=openSurface`, `solid=false`, `closedVolume=false`, coordinate scale and the warning. Mixed solid/surface selections and surface batches refuse; closed-solid STL and Core 3MF retain their prior validation. This does not create a CAD feature or make an open sheet watertight.

The independent real-app [fixture](../../tests/open_surface_stl_independent_api.py) authored a retained radius-20 mm quarter-cylinder sheet, 10 mm high, with exact B-rep area **100π mm²**. Its binary millimeter STL had **36 triangles**, **38 boundary edges**, no edge shared by more than two triangles, measured area **314.059591 mm²**, and bounds x/y [0,20], z [-5,5] mm. Finer ASCII inch output had **72 triangles**, **74 boundary edges**, no over-shared edge, measured area **314.134354 mm²** after multiplying coordinates by 25.4, and the same bounds within serialized precision. Both triangle counts and SHA-256 matched Alloy's completed preview; direct `document.exportStl` produced byte-identical binary output. The authored model, Undo and saved source bytes stayed unchanged. The saved model and outputs are outside git at `../Alloy-reference-records/validation/prt004-open-surface-stl-2026-10-20/independent-final/`.

The accepted Release build used Qt 6.11.2 and `-j4`. Focused `multibody_mesh` passes open-sheet binary/ASCII unit conversion, cancellation/refusals and existing solid/batch regressions. Compiled Qt actual-hit Save As Mesh/Preview checks pass; the native sheet capture shows a readable selected surface label, persistent warning, triangle count and Save button. The independent Apple M4 GPU images show the curved sheet and serialized facet preview at DPR 2. The sheet obscures much of the planar test surface, a preexisting presentation limit owned by PRT-014. Native Save chooser activation and physical input remain release gates. No CI ran, and private editors closed after tests.

Public documented behavior and unknown reference warning/defaults are recorded outside the repository at `../Alloy-reference-records/knowledge/specs/prt004-open-surface-stl-2026-10-20.md`. Open-surface warnings and result classification are explicit Alloy choices. This slice does not certify arbitrary disconnected/multi-face sheet mesh connectivity, surface 3MF, mixed batches or slicer acceptance. Broader mesh export remains PRT-002; native sheet/chooser quality remains PRT-014 and REL-053. Packaged Windows/Linux runtime and physical Mac interaction remain GATE-050.
