# Modeled external Thread — SOL-059/#504

Accepted bounded Mac workflow, 2026-10-17. [The external command record](../../../Alloy-reference-records/knowledge/specs/sol-059-modeled-printable-thread-2026-10-17.md) distinguishes public evidence from Alloy's nominal-profile and interaction choices.

Alloy now authors a retained, editable modeled external thread on a selected finite cylindrical boss face. The native Thread dock and `solid.thread` control command share the same document operation. The supported coarse catalog is M6×1, M8×1.25 and M10×1.5, with right/left direction, Full Length or a bounded axial offset and length. The chosen major diameter must match the actual face. The profile is nominal rounded-root geometry; no tolerance class, printing fit allowance, lead-in, internal thread, tapered thread, or broad standards table is claimed.

The focused backend gate passed size/pitch retargeting to a compatible face, length edits, source-height edit, stale/invalid selection refusal without a document mutation, Undo/Redo, native save/reopen and worker-result adoption. The [current-build real-app gate](../../../Alloy-reference-records/validation/sol059-thread-final/receipt.json) repeated a shorter length edit, refusal, history, upstream edit and reopen. Its binary STL independently read back as one watertight connected component with the expected millimeter bounds. The [native-input receipt](../../../Alloy-reference-records/validation/sol059-thread-native-final/receipt.md) records actual cylindrical-side picking, Full Length preserved at 14 mm, pending Escape with no late commit, preview, physical OK and committed body picking. Captures show the full helix and selection on the Apple M4 hardware OpenGL/Metal driver. Astra independently reviewed code, captures and bounded evidence.

Performance was profiled rather than treated as inevitable kernel cost. A duplicate Boolean `Build()` was removed, reducing isolated M8 geometry from about 1.52 s to 0.80 s. The earlier display path then blocked the UI about 4–7 s because AIS could discard worker triangulation when assigning its own deviation. The [prepared-mesh probe](../../../Alloy-reference-records/validation/thread-performance-2026-10-17/prepared-mesh-preservation/) retained all 121,502 triangles at the same 0.028 mm absolute/0.10 rad display quality through preview and commit. Measured presentation was 166 ms for preview, 106 ms for native commit and 258 ms for direct commit, with 360 ms worst sampled UI heartbeat. Preparation still took about 7 s on the worker and the complete operation roughly 9–10 s. Mesh preservation is deliberately limited to the current prepared Thread result; general presentation responsiveness remains separate work.

The build passed and `git diff --check` was clean. Both private validation instances exited; the pre-existing user-owned Alloy process was preserved. Only this macOS nominal external-thread slice is accepted. Print-fit, complete standard compliance, other systems and all broader Thread modes remain open under ADV-005 and release/platform gates.
