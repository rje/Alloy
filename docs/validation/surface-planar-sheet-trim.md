# SRF-018: retained planar crossing-sheet Trim

This ingredient extends Surface Modify > Trim with a distinct retained sheet-body tool. It accepts one target and one earlier tool, each a local, same-owner, single-line planar Surface Extrude with its original four straight boundaries. The finite tool must actually divide the target into exactly two regions sharing one new intersection edge. Curved/multiple-face sheets, occurrences, modified targets, partial cuts and noncrossing tools refuse. This does not complete the curved iron trials in SRF-016, which remain dependent on SRF-015.

Preselect the target body, start Trim, select the visible tool, then select the target portion to remove. The two regions are independently selectable; selecting the other replaces the first selection. Removal previews red, OK retains the tool and modifies the target, and Cancel leaves authored data unchanged. A visible fit-spline hit takes precedence over a sheet-face hit at the same point; otherwise the tool class follows the actual selected geometry. Change Tools clears either class. Existing paired-sketch Trim remains separate. The shared API accepts `toolBodyId` instead of `toolSketchId`/`toolEntityIds`; `surface.trimBody` performs the same modal tool selection as the viewport. Preview, commit, edit, history and storage share the existing authority.

OCCT Splitter operates on the actual finite target/tool shapes with NonDestructive enabled. No prism or tool extension substitutes for a sheet intersection. Region IDs derive from Trim/source/tool face IDs and signed sides of the oriented tool plane. The exact area centroid confirms the side, and every straight polygon vertex must remain on that side or the intersection plane. The retained Surface Extrude construction guarantees the original target is a convex parallelogram. Exactly two source-face descendants and exactly one new shared intersection edge are required. Original boundaries follow splitter history, with split segments ordered on the retained source curve; the new boundary retains target/tool face and tool body provenance. Ambiguous identity refuses. Reversing the source line reverses the oriented tool normal and therefore the meaning of the signed sides; translating the tool without reversing it preserves region and boundary IDs.
