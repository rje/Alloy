# Analytic constraint pair feedback — SKT-118

Accepted 2026-10-18 for the declared line/circle/arc pairs in Concentric, Collinear, Symmetry and Tangent. The native constraint tools now check eligibility before changing selection. They distinguish a pending first/next pick, a wrong entity type, an unsupported or not-yet-supported pair, a solve failure and an applied relation. A refused second pick keeps the valid first pick and leaves the sketch, evaluation and history unchanged. The explanation remains readable when the Sketch Palette is scrolled to its bottom controls.

At this gate, the Alloy matrix was: Concentric supports circle/circle, circle/arc and arc/arc; Collinear supports line/line; Symmetry supports line/line and arc/arc with a construction axis; Tangent supports line/circle, line/arc and circle/circle. Circle/circle Symmetry was then added under [SKT-121](sketch-circle-symmetry.md); arc/circle and arc/arc Tangent remain planned in SKT-119 and SKT-120. Line/line Tangent is unavailable; Collinear is the common-line command. Mixed Symmetry pairs and noncurve inputs explain their rejection. This matrix records Alloy support, not a complete reference-product parity claim; one-shot multi-pair Symmetry remains unknown under SKT-122.

Four focused native Qt suites passed, including eight refused-pair checks with visible prompt, pending-pick preservation and unchanged authored/evaluated/history state. The same pending circle then recovered into Concentric; its badge selected/deleted, Undo/Redo and saved reopen passed. A real-app API fixture corroborated state and recovery. The final native capture shows the full rejection text above Finish/Cancel, and a recovered badge; the GPU reports Apple M4, OCCT OpenGL 4.1 Metal. Physical OS input and exact reference styling remain unqualified.
