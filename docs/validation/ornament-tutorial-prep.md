## Edits and identity

At the retained eight-body Pattern stage, change count to ten and undo/redo.
Verify total bodies, redistributed angles and stable prefix occurrence UUIDs,
then restore eight before constructing the hub. After the completed Join/Cut,
make a supported source spline or offset edit and require the final connected
body, bore and explicit participant set to rebuild. Check exact authored
undo/redo and reopen the saved original source state.

Join targets are explicit body IDs. Increasing Pattern count after Join does not
silently select the new occurrences; they remain separate bodies. Decreasing it
so a selected participant disappears must refuse atomically unless references
are explicitly repaired. The ingredient covers that refusal. Neither a before-
Join count edit nor a passing final offset edit proves automatic target expansion.

## Acceptance

The whole gate requires source-order movie, editable file, stage captures,
actual valid eight-to-one Join, transverse bore and independently inspected STL.
Keep API, native Qt input, GPU and geometry evidence distinct. Astra reviews the
integrated result and public visual references. Ingredient passes and diagnostic
kernel probes alone cannot close this gate.
