# Pointer Line axis inference (SKT-084)

Pointer-created straight sketch lines near an axis use one shared preview and commit classifier. The current Alloy policy requires at least 2 mm length and at most the smaller of 1 mm or one degree of transverse deviation. Only a free second endpoint is projected; an acquired endpoint must already be aligned. The first click and existing sketch points are never relocated to satisfy inference. The resulting horizontal or vertical relation is retained in the sketch. Control/Command temporarily suppresses this H/V inference. Direct `sketch.line` authoring is unchanged. The public source establishes automatic H/V behavior and modifier suppression, but does not establish this numeric threshold.

Focused `sketch_pointer_axis_inference` core validation covers a diagonal ending at the origin, chained H/V lines, exact retained relations, unchanged old points, misaligned acquired endpoint suppression, and the explicit uninferred path. The actual application tutorial smoke passed at `../Alloy-reference-records/deliverables/sketch-expression-exercise-2026-10-14/native-13/`: bottom H and right V are retained, the top is Perpendicular, and the final closed polygon is 120 × 170 mm with 17,400 mm² area. The other three profiles, 45 mm slot span, R5 cap, `d3 + 50` update, undo/redo, save and reopen also passed. The captured canvas shows retained H/V badges and readable dimensions. A focused native14 hover check also asserted the H preview cue visible after actual Qt pointer movement and captured it in `horizontal-preview-cue.png`. This evidence does not exercise a triggered solve-conflict refusal or native Control/Command suppression; those paths were source-reviewed and bounded by the core checks.

The tutorial harness opens the application's existing Qt command menu with a nonblocking popup because QtTest mouse press enters a native synchronous menu loop on this macOS build. It then delivers actual Qt submenu hover and item clicks, followed by pointer and keyboard modeling input. Physical toolbar opener parity remains unverified by this run.
