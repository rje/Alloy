# Retained circular Coil — SOL-060/#505

Accepted bounded first-v1 functionality at `01a8be7` after independent Sol source/evidence review: **Solid > Create > Coil** creates one editable circular-section helical New Body on XY. Diameter measures the helix centerline; numeric Center X/Y place its axis at z=0. The supported Type is Revolution And Pitch, Section is Circular, Section Position is On Center, and rotation is clockwise viewed from +Z looking toward XY while rising along +Z. Chosen Alloy defaults are Diameter 20 mm, Pitch 5 mm, Revolutions 3 and Section Size 2 mm. These numbers, fixed viewpoint and numeric XY route are Alloy policy, not a claim of exact reference defaults or full placement parity. The dated public command contract and provenance remain outside the repository at `../Alloy-reference-records/knowledge/specs/sol060-coil-2026-10-24.md`.

The native dock and local `solid.coil` command author the same retained feature. `primitive.coil` opens it; ordinary Preview, OK, Cancel and Escape use existing shared sessions. Timeline edit reopens the same dimensions and identities. Pitch accepts a direct named user length; a user-parameter edit recomputes the same Coil and later Move. Revolutions is dimensionless, including refresh after preview. A blank document frames the first successful Coil preview once so the actual geometry is visible without a manual camera setup.

The existing serial geometry worker evaluates a detached candidate, its historical stage when needed, and its display tessellation. A session/base/revision/generation/input check precedes publication. Cancel discards the result while kernel work finishes; changed input invalidates earlier OK intent, and unavailable typed Pitch cannot publish an older numeric result. UI and direct API commit the exact prepared candidate through the same retained transaction guard. Unchanged input updates preserve the prepared preview. This keeps meshing off the UI thread without weakening downstream recompute/refusal.

OCCT constructs a cylindrical-surface p-curve helix, builds its 3D curve and sweeps a normal circular wire with `BRepOffsetAPI_MakePipeShell`/`MakeSolid`. Before publishing a result, it requires one valid solid and `BRepAlgoAPI_Check` small-edge/self-interference acceptance. The conservative supported range is 0.25–20 revolutions, maximum 100,000 mm axial centerline span, positive dimensions in the ordinary 0.001–100,000 mm range, and a section smaller than the centerline diameter and the minimum adjacent-turn separation. The separation check finds the right derivative root on [π,2π] and compares both endpoints. This guard also conservatively refuses some partial coils that could be nonintersecting; it is a declared supported-range refusal, not a proof that every refused partial coil is invalid. Invalid edits leave authored geometry/history untouched and clear a stale preview.

The focused kernel fixture checks analytic normal-tube volume and a quarter-turn's real end-cap centers `(10,0,0)` and `(0,-10,1.25)`, tangent-normal cap planes and circular section area. This independently witnesses clockwise phase, pitch and section diameter. It also refuses overlapping and touching adjacent turns. The real-app [coil_api.py](../../tests/coil_api.py) checks preview/Cancel, named Pitch source edits, a retained downstream Move, Revolutions edit, refusal/recovery, Undo/Redo, source-independent save/reopen and two independently decoded STL outputs. The native `coilPrimitivePanel` fixture in [responsive_controls.cpp](../../tests/responsive_controls.cpp) delivers actual-hit menu, field, button and Timeline input after initial activation only.

A first synchronous real-app pass found a visible Revolutions `mm` suffix from the shared refresh and a tiny unframed initial preview; both were corrected before native qualification. Its measured default preview took 4.58 s and direct commit 4.89 s. Focused phase tracing showed only about 88 ms for primitive construction/checks (including 81 ms self-interference) and 63 ms for summary, identifying display tessellation/publication as the cost. Coil now prepares display meshes on the existing worker and reuses the prepared evaluation for commit. Final asynchronous dispatch/publication, source/history and completed-work timings are reported separately below; total work duration is not a claim that main-thread latency passed.

Final focused kernel checks, actual-app API lifecycle and native Coil controls pass. The independent Sol source/evidence review accepts this bounded result. Evidence is retained at `../Alloy-reference-records/validation/coil-2026-10-24/`: `api-responsive/` contains the saved model and two independently decoded binary STL files, with exact kernel summaries and the completed request transcript in `report.json`; `native/receipt.json`, `native-coil-preview.png`, `native-final.png` and `native-coil.alloy` record final native controls and presentation. The API geometry run preceded only the Coil opaque-preview styling change; the final native captures qualify that presentation change. An older `synchronous-baseline-report.json` is retained as diagnostic evidence, not current native acceptance.

For the default D20/P5/N3/section2 preview, asynchronous dispatch took **77.6 ms**, pending Inspect **155.7 ms**, and pending Cancel **52.5 ms**. The completed preview took **5.151 s**: worker full evaluation **329 ms**, historical stage **0 ms**, display meshing **4543 ms**, main-thread publication including refresh/recovery **225 ms**. Its heartbeat advanced 194 ticks with a 59 ms maximum gap. Direct named-Pitch creation at Center (4,−3) completed in **7.908 s** off-thread. Changing the named Pitch to 7 mm with a retained +3 mm Z Move took **5.883 s** through the existing parameter-update path. Editing the same feature to four revolutions then committed its exact prepared result in **436 ms**. Undo of that edit took **5.645 s**; Redo took **171 ms**. These are specific fixture measurements, not broad performance qualification. These pre-REL-056 measurements remain diagnostic baseline; the accepted follow-up below supersedes historical mesh behavior and the scoped numeric-Pitch dispatch path.

The two STL readbacks at four revolutions/Pitch 7 and 9 mm contain **81,356** and **82,764** triangles. Each is one closed consistently oriented component with Euler characteristic 2 and finite unit normals aligned to winding. Volumes are **788.9884 mm³** and **792.2500 mm³**, respectively about 0.69% and 0.67% below analytic tube volumes at the chosen export tessellation settings; measured bounds agree within 0.09 mm. This qualifies the declared printable geometry/export subset, not physical print fit.

The final 1360×850 native fixture passes 3/3 QtTest phases at DPR 2. Actual-hit Create entry, pending Preview/Cancel, field input, unchanged-Name preview reuse, OK and Timeline edit are covered; dispatch, Cancel and the prepared creation OK each satisfy the 500 ms bound. It observes native/Qt activation throughout the creation and edit-Cancel prefix without focus repair. The last asynchronous Timeline edit OK commits the same feature/body IDs but its after-closure receipt reports inactive native/Qt focus; no subsequent native input was delivered or claimed. Post-closure native continuation therefore remains unqualified. Undo/Redo and save/reopen use the shared API. The GPU reports Apple M4, OpenGL 4.1 through Metal, 4× MSAA and a 2216×1096 native framebuffer. The final opaque preview and committed coil are smooth and the numeric controls are readable. The Release build uses Qt 6.11.2 and OCCT 7.9.3 from `build-preview-release` with `-j4`; all private editors closed and the user-owned instance was preserved. Broader plane/center/diameter gestures, arbitrary planes, direction choices, sections/positions, taper, end treatment and Boolean operations remain ADV-005; physical device input, matched-reference styling and Windows/Linux packaged runtime remain release gates. No paid CI was started.
