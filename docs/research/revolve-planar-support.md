# Full-Revolve radial planar support

Source record `ornament-pattern-20261013` independently establishes a vertical
80 mm profile edge, a horizontal bottom edge 5 mm rightward, and a right-bulging
R50 arc joining their outer endpoints. Full 360 Revolve about the vertical edge
is followed by removal of the generated bottom disk with Inside Shell 5. The
vertical origin plane label and initial arc seed clicks are unspecified; the
bounded fixture chooses XZ and mathematically derives the exact arc center.
Detailed provenance and original public images remain outside the repository.

The exact source profile and full revolution were proven through OCCT before
UI work. The actual planar disk comes from `BRepPrimAPI_MakeRevol::Generated`
on its retained radial profile edge. `BRepOffsetAPI_MakeThickSolid` removes that
real disk with the existing Inside 5/sharp-join settings. The resulting valid
closed solid has an annular open-bottom rim and a cavity. Actual normal-ray
intersections at three regular meridian points, away from seam/apex, measure
5 mm wall thickness within 1e-5 mm. This does not assert uniform tip/seam thickness.
Initial nearest-distance seam probes were unsuitable; the final proof uses
actual intersections and material/cavity/exterior classification, not widened
wall acceptance or a changed Shell algorithm.

The bounded implementation retains only full-Revolve faces generated by actual
retained straight radial edges perpendicular to the revolution axis. It admits
one unique Generated face present in the actual result solid and verifies its
planarity and axis-parallel normal. UUIDv5 uses producer and retained sketch,
profile, entity and endpoint-contact identities, never current dimensions or
nearest-height matching. Missing or ambiguous descendants publish structured
`generatedPlanarSupportErrors`, with no arbitrary face substitution; a dependent
Shell cannot resolve that support. Unrelated legal Revolve profiles remain valid.

Each support descriptor has role `revolve.radial` and optional evaluated
`provenance` containing the retained generator identity. It supplies the existing
producer/body/face triple used by selection, Shell and supported sketches. The
frame origin is the intersection of the actual generated plane and actual axis;
its radial U and parametric plane normal determine a right-handed frame. OCCT
may return an indirect plane placement, so the normal uses actual X×Y plus the
solid-held face orientation, rather than blindly taking its placement Z axis.
The provenance survives existing evaluated support copies and transfer rules;
no generated face is separately authored or saved as cached geometry.

Existing native face picking, Shell controls and shared inspection expose these
new records. Shell explicitly refuses duplicate current producer/body/face
matches. The existing partial-Revolve start/end supports remain unchanged;
curved generated faces, broader partial generation, edge projection expansion
and the full ornament tutorial remain with their existing owners. The current
bounded increment adds no independent surrogate cap or partial-revolve substitute.
