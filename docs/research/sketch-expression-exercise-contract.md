The first two driving length dimensions in this selected source order are the slot's 45 mm length and R5 radius. Rough circle/rectangle and the Center to Center Slot itself should add no driving dimensions, so the polygon's vertical dimension can be the third driving length, `d3`. Angle and virtual projected dimensions do not consume the length-name sequence. A monotonic per-sketch counter keeps names from being reused after deletion. This exact `d3` allocation is an Alloy policy; only the lesson's observed `d3` is evidence of the reference's naming behavior. Display names and stored reference UUIDs are separate. A new ambiguous bare identifier shared by a local dimension and a user parameter refuses; existing stable bindings never retarget. A direct local-dimension formula and an existing user-parameter binding are exclusive. General dimension renaming remains with PAR-001.

For direct sketch dimensions, a bare numeric literal in length addition inherits the document length unit captured when the expression is entered, so the source's metric `d3 + 50` adds 50 mm even if display units later change. Existing PAR-006 user-parameter expressions keep their scalar-literal rule. The expression is entered in the existing inline dimension editor after annotation placement; the canvas shows evaluated numeric length, while editor and inspection expose the formula. Legacy saved numeric sketches must reopen with their original coordinates. The source ends this exercise before deleting the training geometry; a solid extrusion, full-constraint claim, generalized parameter graph and exact screenshot parity are outside TUT-024.
