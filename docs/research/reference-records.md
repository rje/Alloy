# Reference provenance and publication boundary

Updated 2026-10-11. Public research findings use stable IDs from
[the source registry](../backlog/sources.json). Foundation-library documentation
remains linked directly. Reference-specific URLs and downloaded public images
are retained separately in `../Alloy-reference-records/`, outside this repository.
The location is relative to the repository root, not this document.

The local records contain `reference-map.json`, the original source registry,
and the original image provenance manifest. Their URLs were public when
retrieved; a local record is not authorization to access account-gated material.
Only publicly available documentation, screenshots, instructions and published
API descriptions may be used. Never operate or inspect proprietary reference
software, installations, binaries, assets or private APIs. No reference images
are application assets or redistributed build inputs.

The public checkout builds and runs without these records. Researchers without
the local archive must establish permitted public evidence and record its date
before asserting additional compatibility. Distinguish documented behavior,
screenshot observations, inference and unknowns. The original functional scope,
familiar interaction requirements and independently authored implementation
remain in force. Publication cleanup alone does not establish legal compliance.
